不透明化の画素確認(R-B)

実際のブラウザの Canvas で、魚 6 種・オト・エビ・貝(横向き・前面ガラス)を、赤と緑の 2 通りの背景に描いて画素を比べます。 npm run serve → http://localhost:8000/tests/pixels.html で開きます(外部リソースなし。js/ のモジュールを import するだけ)。

背景 赤 = (220,40,40)、緑 = (40,200,40)。画素の差 Δ は 0〜255 の値の差。不透明度の推定値 α = 1 − (赤背景の画素 − 緑背景の画素) / (背景の差)(R と G チャンネルの平均)。 プローブ(判定する画素)は、PAINT の形から決めた位置で、下の図に印を付けています(青 = 体、マゼンタ = ひれの膜、橙 = エビの重なり、水色 = エビの重ならない体)。
