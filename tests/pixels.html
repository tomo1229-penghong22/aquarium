不透明化の画素確認(R-B)

実際のブラウザの Canvas で、魚 6 種・オト・エビ・貝(横向き・前面ガラス)を、赤と緑の 2 通りの背景に描いて画素を比べます。 npm run serve → http://localhost:8000/tests/pixels.html で開きます(外部リソースなし。js/ のモジュールを import するだけ)。

判定条件(R1b):背景の物体(岩・流木・水草・浮草)の判定は、3 倍の解像度で描いて行う。内部 = 周囲 2 画素(5x5)がすべて強く塗られた画素。内部の透けた画素のうち、「すき間」(別々の不透明な図形のあいだの、幅が約 5 画素以下の背景。4 方向のどれかで、同じ距離 1〜3 画素の両側が不透明な本体の画素)は物理的な穴ではないので許容し、すき間でないもの(面状)が 0 であることを判定する。浮草の根(細く淡い組織。rgba(225,215,185,0.55) の細い線)は、ひれの膜と同じ「物理的に透ける部分」として許容し、その線(stroke)を描かずに、葉の本体だけで判定する。種類ごとに(関数ごとに)分けて判定し、透けた画素は図に印で示す(マゼンタ = すき間、橙 = 面状)。

背景 赤 = (220,40,40)、緑 = (40,200,40)。画素の差 Δ は 0〜255 の値の差。不透明度の推定値 α = 1 − (赤背景の画素 − 緑背景の画素) / (背景の差)(R と G チャンネルの平均)。 プローブ(判定する画素)は、PAINT の形から決めた位置で、下の図に印を付けています(青 = 体、マゼンタ = ひれの膜、橙 = エビの重なり、水色 = エビの重ならない体)。
