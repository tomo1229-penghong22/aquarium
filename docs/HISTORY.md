# これまでの経緯

claude.ai のチャットで作ってきた内容です。各段階の依頼と、そのとき決めたことを残します。

以前の公開先:claude.ai のアーティファクト(https://claude.ai/artifact/162zdJqm9DkE7nBha7HFcg)。現在は GitHub Pages(https://tomo1229-penghong22.github.io/aquarium/)で配信している(下の 10・11 を参照)。

---

## 1. 初版

**依頼**:熱帯魚の水槽。メジャーな魚を数種類、数と共に選べる。水草と温度計。水温は「少し冷たすぎる」から「放っておくとひどく弱る」までの範囲で調整。水草の揺れは自然に。やわらかい自然光が全体に当たる。

**決めたこと**
- 魚は6種。種ごとに適温と泳ぎ方(群れ・層・速さ)を変える。
- 水温は 18〜34℃。設定温度に向かって少しずつ変わる(ヒーターの熱慣性)。
- 低温は代謝低下で動きが鈍る(体調は下限 0.38 で止まる)。高温は溶存酸素の低下で水面に集まり、放置すると大きく弱る。
- 「時間の流れ」で体調変化だけを早送りできる。
- 水草の揺れは、ノイズを重ねた水流と、根元から先端へ遅れて伝わる波で表現。
- 光は光の筋とコースティクス。コースティクスは魚にも水草にも落ちる。

## 2. 全体を美しく

**依頼**:もっと美しく。ただし完全に写実的にはしない。

**決めたこと**:光と色の調和を重視した、少しイラスト寄りの方向。翡翠色の水、二層の光の筋、水面のきらめき、光の筋の中で光る粒子、奥のぼかした草原(空気遠近法)、流木とシダ、タイガーロータス、浮草、魚の縁の光とひれの筋、底に落ちる影。

## 3. 夜モード

**依頼**:今までが昼モード。夜モードを追加し、自然光を消して、水槽上部の白色 LED でライトアップ。

**決めたこと**:LED 器具を描き、真上からの青白い光、まっすぐ落ちる細い光の筋、くっきりしたコースティクス、下と端ほど暗い照明、暗い部屋。約 1.4 秒でなめらかに移行。器具は昼も消灯状態で表示。

## 4. 拡大ポップアップ

**依頼**:「魚を選ぶ」で魚にマウスオーバーしたら拡大表示。ごく自然に、ときどきユーモラスに動く。

**決めたこと**:小さな水槽の中で漂い、目はカーソルを追う。仕草は自然なものとユーモラスなものを混ぜ、種ごとの特技を用意(コリドラスのウインクは実際の習性)。擬音は控えめに。

## 5. ポップアップを閉じる不具合

**依頼**:マウスがアイコンから離れたらポップアップも消す。

**原因と対処**:名前の欄にも反応していたこと、クリックで残るフォーカスが表示を維持していたことが原因と考えられた。アイコンだけに反応させ、マウス由来のフォーカスでは開かないようにし、カーソルがアイコン外にあれば必ず閉じる判定を追加。

## 6. 半透明感

**依頼**:もう少し全体的に半透明感を。

**決めたこと**:対象は水槽の中の表現。魚は種ごとの透明度(テトラが最も透ける)、水草は奥ほど透ける。水を一段明るく澄ませ、霞と周辺減光を弱め、光を少し強めた。操作パネルは変更していない(すりガラス化は保留)。

## 7. 全画面モード

**依頼**:水槽に全画面モード。標準的な操作で切り替え。

**決めたこと**:ボタン・F キー・ダブルクリックで入り、Esc でも戻れる。縦横比に合わせて情景を作り直す。操作がないとボタンとカーソルを隠す。Fullscreen API が使えない環境では固定表示の代替モードに自動で切り替える。

## 9. ES Modules への分割

**依頼**:iPad/iPhone で、PC や LAN に頼らず単独で動かしたい。魚の種類や器材を増やしやすくしたい。

**決めたこと**:単一ファイル制約を撤廃した(claude.ai での公開をやめ、iPad/iPhone 向けに PWA として配信する方針)。`index.html` は マークアップと CSS だけにし、JavaScript は `js/` の 8 モジュール(素の ES Modules、ビルドなし)に分けた。ロジックと実行順は変えていない。分割前後で描画命令の列を記録して比較し(`npm run drawlog`)、完全に一致することで同一性を確かめた。`file://` では開けなくなったため、HTTP サーバ経由で開く。

## 10. PWA 化と GitHub Pages での公開

**依頼**:iPad/iPhone で、オフラインでもホーム画面から起動できるようにしたい。

**決めたこと**:`manifest.webmanifest`、`sw.js`(全ファイルの事前キャッシュ)、`icons/` を足して PWA にした。GitHub Pages(サブパス配信)に置くため、パスはすべて相対にした。ノッチとホームバーは `env(safe-area-inset-*)` で避ける。Jekyll の処理は無効にした。`?perf` で描画の区間ごとの所要時間を見られるようにした(iPhone では 95 匹でも 60fps、draw 約 4ms)。

## 11. 群れの修正・release・タップの修正

**群れ**:ネオン・ラミーの群れが数珠つなぎに見えたので、縦の散らばりを 0.6 から 1.0 に広げ、同種間の分離を進行方向の前後に長い楕円(1.3 倍)にした。速度がほぼ 0 のとき全同種から押される不具合は、基準速度の 10% 未満なら円形の分離に戻して直した。群れの形は `npm run school` で計測する。

**release**:`sw.js` の `CACHE_VERSION` の上げ忘れを防ぐため、`npm run release`(確認は `--dry-run`)で、確認・`npm test`・版の更新・コミット・push をまとめて行うようにした。

**テストの高速化**:T2(分割)に伴う副次的な効果。テストが、vm で `<script>` を実行する方式から、グローバルにモックを置いて import する方式に変わり、2〜3 分から約 30 秒になった(Canvas のモックの Proxy は今も使っている)。

**T8(タップ)**:iOS Safari でアイコンをタップしてもポップアップが開かなかった問題を、`click` の `pointerType` に頼らず、直前の `pointerdown` の種別で判定して修正した。実機で確認済み。
