## 既知の課題・未確認の点

これまでの動作確認は、Node 上のモックを使ったテスト(`tests/smoke.mjs`)が中心です。**実際のブラウザでの見た目と操作は、Claude Code 側で改めて確認してください。**

- **ブラウザでの目視確認が必要**:特に、夜モードの明るさ、半透明にした水草の重なり、縦長画面の全画面表示。
- **エンゼルフィッシュのポップアップ**:餌を追って上へ泳ぐとき、長い背びれが枠の上で切れることがある。
- **Safari でのクリック判定**:`click` イベントに `pointerType` がない環境では、マウスでアイコンをクリックすると、ポップアップが閉じたり開いたりする可能性がある。
- **iframe 内の全画面**:埋め込み先が全画面を許可していないと、代替モードになる(想定どおりの動作だが、見え方を確認したい)。
- **動きを減らす設定**:`prefers-reduced-motion` は UI の遷移にしか反映していない。水槽のアニメーション自体は減らしていない。
- **テストの所要時間**:2〜3 分かかる。Canvas のモックに Proxy を使っているのが主な理由。

## 改善の候補

### 構成・開発環境
1. **モジュール分割とビルド**:`src/` に分けて書き、ビルドで単一 HTML に戻す(例:Vite + `vite-plugin-singlefile`)。成果物が単一ファイルであるという制約は維持する。分割の単位は、`index.html` の区切りコメントがそのまま目安になる。
2. **見た目の回帰テスト**:Playwright で昼/夜・各水温のスクリーンショットを撮って比較する。乱数を固定できるよう、魚の初期配置にもシードを通す。
3. **テストの高速化**:Canvas のモックを Proxy から単純なオブジェクトに置き換える。

### 表現
4. 操作パネルとポップアップの枠にも、すりガラスのような半透明感を出す(第6段階で保留した案)。
5. 夜モードの LED の色温度を選べるようにする(昼白色・電球色など)。
6. 朝・夕の時間帯や、昼夜の自動切り替え。

### 機能
7. 魚の種類を増やす(ベタ、オトシンクルス、ゼブラダニオなど)。追加手順:`SPECIES` と `ORDER` に追加 → `PAINT` に描画関数 → `NOTES` と `POP_L` → テストの確認。
8. 水質(酸素・水換え)や餌やりを要素として加える。
9. 水槽の中の魚をクリックすると、その魚の情報を出す。
